# Civitai Model Info & Media Saver v2.0.0

Расширение для Chrome (Manifest V3), которое сохраняет полную информацию о моделях/LoRA с Civitai и все примеры изображений и видео в локальную папку без скачивания тяжёлых весов `.safetensors`.

## Что нового в v2.0.0

- **Безопасная архитектура хранения (origin расширения):** выбор и авторизация локальной папки (`File System Access API`) перенесены в Side Panel и Offscreen Document — сайты `civitai.com` / `.red` / `.green` не получают доступа к вашей файловой системе, а одна выбранная папка работает на всех зеркалах.
- **Потоковая запись видео и проверка сигнатур:** медиафайлы пишутся напрямую потоком без лимита 35 МБ и лишнего расхода RAM, а `Content-Type` и magic bytes проверяются до записи (страницы ошибок CDN больше не сохраняются под видом `.jpeg`/`.mp4`).
- **Компактный виджет в Shadow DOM:** не конфликтует со стилями сайта, показывает прогресс-бар с отменой, кнопку повтора ошибочных файлов и копирование `<lora:имя:вес>` в 1 клик.
- **Боковая панель (Chrome Side Panel) + горячая клавиша `Alt+Shift+S`** и бейдж статуса (`✓` / `v`) на иконке расширения.
- **Прокачанная база моделей (`database.html`):** сортировка, фильтры по избранному и видео, персональные заметки, отмена удаления (Undo), импорт JSON-бэкапов (Merge/Replace), сканирование локальной папки для синхронизации и определения весов `.safetensors` на диске, CSV с UTF-8 BOM.
- **Obsidian-friendly Markdown + улучшенная офлайн-копия HTML:** YAML frontmatter, безопасная санитизация HTML, нативный `<dialog>`-лайтбокс для фото и видео, рабочий поиск по промптам и переключение RU/EN.

## Установка

1. Откройте в браузере `chrome://extensions/` (Chrome, Edge, Brave).
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите корневую папку репозитория.

## Использование

1. Откройте любую страницу модели на `civitai.com`, `civitai.red` или `civitai.green`.
2. Выберите локальную папку через Side Panel или кнопку **«Выбрать папку»** (доступ запрашивается безопасно от имени расширения).
3. Нажмите **Save Model Info & Media** (или `Alt+Shift+S`).
4. Используйте **Side Panel** или **Базу моделей** для быстрого поиска, копирования `<lora:...>` и синхронизации с диском.
