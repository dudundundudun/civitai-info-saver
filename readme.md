# Civitai Model Info & Media Saver

Расширение для Chrome (Manifest V3), которое сохраняет полную информацию о моделях/LoRA с Civitai и все примеры изображений и видео в локальную папку без скачивания тяжёлых весов `.safetensors`.

## Что умеет

- **Встраивается прямо на страницу модели** (под блоком Download, над Details) и работает на `civitai.com`, `civitai.red` и `civitai.green`.
- **Сохраняет напрямую в `Documents/civitred/<Название LoRA>/`** (через File System Access API) или в `Downloads/civitred/`.
- **Проверяет дубликаты перед скачиванием**: при открытии страницы модели показывает, есть ли эта LoRA (или другая её версия) уже в папке или локальной базе, и умеет пропускать уже скачанные медиафайлы.
- **Выгружает данные сразу в нескольких форматах**:
  - `.html` — автономная офлайн-копия страницы модели в стиле Civitai с галереей, промптами и кнопками копирования;
  - `.md` — Markdown-карточка с таблицей параметров и ссылками (удобно для Obsidian);
  - `.txt` — чистая текстовая сводка;
  - `.json` и `.civitai.info` — метаданные для A1111 / Forge / ComfyUI;
  - Все примеры картинок и видео (`.mp4`) + опционально `<имя_файла>.preview.<ext>` для WebUI.
- **Встроенная база моделей (`Search DB`)** — поиск по сохранённым LoRA, триггер-вордам, хешам и тегам, плюс экспорт каталога в HTML, CSV и JSON.

## Установка

1. Скачай или склонируй репозиторий (или распакуй ZIP-архив с расширением).
2. Открой в браузере `chrome://extensions/` (работает в Chrome, Edge, Brave).
3. Включи **Режим разработчика** (Developer mode) в правом верхнем углу.
4. Нажми **Загрузить распакованное расширение** (Load unpacked) и выбери папку с файлами расширения.

## Использование

1. Открой любую страницу модели на Civitai.
2. В появившейся панели нажми **«Выбрать папку»** и укажи `Documents` (внутри автоматически создастся папка `civitred`).
3. Выбери нужные форматы и структуру подпапок, затем нажми **Save Model Info & Media**.
4. При повторном заходе на уже сохранённую модель панель подсветит статус наличия файлов в папке.
