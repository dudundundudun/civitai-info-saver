================================================================================
CIVITAI MODEL INFO & MEDIA SAVER v2.0.0 - CHROME EXTENSION (MANIFEST V3)
================================================================================

HOW TO INSTALL IN CHROME / BRAVE / EDGE:
1. Open Chrome and go to:  chrome://extensions/
2. Turn ON the "Developer mode" toggle in the top-right corner.
3. Click "Load unpacked" and select this extension folder.
4. Visit any Civitai model page (civitai.com / civitai.red / civitai.green).

WHAT'S NEW IN v2.0.0:
- Extension-Origin File System Access (Offscreen + Side Panel): Your local folder
  handle lives safely inside the extension origin instead of Civitai's IndexedDB.
- Streaming Media Downloads: Streams images & large videos straight to disk
  with Content-Type + magic-byte validation (no 35 MB cap, no corrupt HTML saves).
- Shadow DOM In-Page Widget: Compact collapsible controls, progress bar with
  Cancel, Retry Failed Media button, and 1-click <lora:name:weight> copy.
- Chrome Side Panel + Keyboard Shortcut (Alt+Shift+S) + Tab Status Badges.
- Upgraded Database Catalog: Sorting, Favorites, Personal Notes, Undo delete,
  JSON backup Import (Merge/Replace), Local Folder Scan, and UTF-8 BOM CSV.
- Obsidian YAML frontmatter in Markdown + hardened, searchable Offline HTML.
